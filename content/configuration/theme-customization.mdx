<En>

MC-Vector includes 9 built-in themes.

## Available Themes

| Theme | Style |
|-------|-------|
| **System** | Automatically follows OS light/dark mode |
| **Dark** | Default sleek dark theme |
| **Dark Blue** | Dark with deep blue accents |
| **Grey** | Softer, low-contrast dark theme |
| **Forest** | Dark with green, nature-inspired accents |
| **Sunset** | Warm orange and red tones |
| **Neon** | High-contrast cyberpunk-inspired theme |
| **Coffee** | Warm, brown-tinted dark theme |
| **Ocean** | Deep aquatic blue theme |

## How to Change the Theme

1. Open the **Settings** menu (gear icon in the sidebar).
2. Go to the **Appearance** section.
3. Select a theme from the dropdown — the app updates instantly, no restart needed.

## Config File Location

Theme preference is stored in `config.json` (Tauri Store):

| OS | Path |
|----|------|
| macOS | `~/Library/Application Support/MC-Vector/config.json` |
| Windows | `C:\Users\<user>\AppData\Roaming\MC-Vector\config.json` |

</En>

<Ja>

MC-Vectorには9種類のビルトインテーマが用意されています。

## 利用可能なテーマ

| テーマ | スタイル |
|--------|----------|
| **System** | OSのライト/ダークモードに自動連動 |
| **Dark** | デフォルトのスッキリダークテーマ |
| **Dark Blue** | ダークブルーアクセントのダークテーマ |
| **Grey** | コントラストを押さえたソフトなダークテーマ |
| **Forest** | 池葉をイメージしたグリーン系ダークテーマ |
| **Sunset** | オレンジ・レッドの温かみのある夕景テーマ |
| **Neon** | 高コントラストなサイバーパンク風テーマ |
| **Coffee** | ブラウンを基調としたウォームなダークテーマ |
| **Ocean** | 深海をイメージしたアクアブルーテーマ |

## テーマの変更方法

1. サイドバーのギアアイコンから**Settings**を開きます。
2. **Appearance**セクションでテーマを選択します。
3. ドロップダウンから選ぶだけで即座に適用されます。再起動は不要です。

## 設定ファイルの場所

テーマ設定は`config.json`（Tauri Store）に保存されます：

| OS | パス |
|----|------|
| macOS | `~/Library/Application Support/MC-Vector/config.json` |
| Windows | `C:\Users\<ユーザー名>\AppData\Roaming\MC-Vector\config.json` |

</Ja>
