<En>

MC-Vector's **Console** view gives you a live stream of your server's log output and lets you execute commands directly from the app.

## Live Log Streaming

Open the **Console** tab in any server to see logs as they appear in real time.

| Feature | Details |
|---------|---------|
| **ANSI Colors** | 16-color support — INFO, WARN, ERROR are visually distinct |
| **Auto-scroll** | Follows new output when within **120 px** of the bottom |
| **Log buffer** | Last **2,000 lines** kept in memory |

Scroll up to pause auto-scroll and review history.

## Sending Commands

Type any server command into the input field at the bottom and press **Send** (or Enter).

<div className="bg-blue-900/20 border border-blue-500/50 rounded-md p-4 my-6">
<div className="text-blue-400 font-bold mb-1">Note</div>
<div className="text-sm text-gray-300">Do not include a leading slash. Type <code>say Hello</code>, not <code>/say Hello</code>.</div>
</div>

```text
# Give a player items
give Steve diamond 64

# Change the weather
weather clear

# List online players
list
```

## ngrok Address Display

If ngrok is active, the Console header alternates between showing `localhost` and the public ngrok URL every **3 seconds** so you can quickly copy it to share with friends.

## Accessing Log Files

Server logs are written to the server's `logs/` directory:

| File | Contents |
|------|----------|
| `latest.log` | The current session's log |
| `YYYY-MM-DD-1.log.gz` | Compressed archives of previous sessions |

To browse these files, switch to the **Files** tab and navigate to `logs/`.

</En>

<Ja>

MC-Vectorの**Console**ビューでは、サーバーのログ出力をリアルタイムで確認し、アプリから直接コマンドを実行できます。

## ライブログストリーミング

任意のサーバーで**Console**タブを開くとリアルタイムでログを確認できます。

| 機能 | 詳細 |
|------|------|
| **ANSIカラー** | 16色対応 — INFO、WARN、ERRORが視覚的に区別できる |
| **自動スクロール** | 下端から**120px以内**にいると新しい出力に自動追従 |
| **ログバッファ** | 直近の**2,000行**をメモリに保持 |

上にスクロールすると自動スクロールが一時停止し、ログ履歴を確認できます。

## コマンドの送信

画面下部の入力欄にコマンドを入力して**Send**（またはEnter）を押すと実行されます。

<div className="bg-blue-900/20 border border-blue-500/50 rounded-md p-4 my-6">
<div className="text-blue-400 font-bold mb-1">注意</div>
<div className="text-sm text-gray-300">コマンドの先頭にスラッシュは不要です。<code>say Hello</code>と入力してください（<code>/say Hello</code>ではなく）。</div>
</div>

```text
# アイテムを配布
give Steve diamond 64

# 天気を変更
weather clear

# オンラインプレイヤーを表示
list
```

## ngrokアドレスの表示

ngrokが有効な場合、コンソールヘッダーは`localhost`と公開ngrok URLを**3秒ごと**に交互に表示します。友達に共有するURLをすぐにコピーできます。

## ログファイルへのアクセス

サーバーのログはサーバーの`logs/`ディレクトリに保存されます：

| ファイル | 内容 |
|--------|------|
| `latest.log` | 現在のセッションのログ |
| `YYYY-MM-DD-1.log.gz` | 過去のセッションの圧縮アーカイブ |

これらのファイルを確認するには、**Files**タブに切り替えて`logs/`フォルダーに移動してください。
